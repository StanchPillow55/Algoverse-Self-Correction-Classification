To solve this problem, we need to use the relationship between the number of heads and legs of emus to find the number of emus in Farmer Brown's flock.

Given information:
- The total number of heads and legs in the flock is 60.

Step 1: Understand the characteristics of emus.
- Emus have 1 head and 2 legs per bird.

Step 2: Set up an equation to represent the relationship between the number of heads and legs.
Let x be the number of emus in the flock.
Total number of heads = x
Total number of legs = 2x

Step 3: Write an equation to represent the given information.
Total number of heads and legs = 60
x + 2x = 60

Step 4: Solve the equation for the number of emus.
3x = 60
x = 60 / 3
x = 20

Therefore, Farmer Brown's flock has 20 emus.

Final answer: Farmer Brown's flock has 20 emus.
