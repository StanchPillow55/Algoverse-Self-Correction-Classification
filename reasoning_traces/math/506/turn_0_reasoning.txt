To solve this problem, we need to find the average distance Terese runs on each of the days she runs.

Given information:
- On Monday, Terese runs 4.2 miles.
- On Tuesday, Terese runs 3.8 miles.
- On Wednesday, Terese runs 3.6 miles.
- On Thursday, Terese runs 4.4 miles.

Step 1: Add up the distances Terese runs on each day.
Total distance = 4.2 miles + 3.8 miles + 3.6 miles + 4.4 miles = 16 miles

Step 2: Determine the number of days Terese runs.
Terese runs on 4 days: Monday, Tuesday, Wednesday, and Thursday.

Step 3: Calculate the average distance Terese runs on each day.
Average distance = Total distance / Number of days
Average distance = 16 miles / 4 days = 4 miles

Therefore, the average distance Terese runs on each of the days she runs is 4 miles.
