Given information:
- Half of the total sales are laptops
- One-third of the total sales are netbooks
- The remaining sales are desktop computers
- The total number of computers sold is 72

Step 1: Calculate the number of laptops sold.
Since half of the total sales are laptops, we can calculate the number of laptops as:
Number of laptops = 1/2 × 72 = 36 laptops

Step 2: Calculate the number of netbooks sold.
Since one-third of the total sales are netbooks, we can calculate the number of netbooks as:
Number of netbooks = 1/3 × 72 = 24 netbooks

Step 3: Calculate the number of desktop computers sold.
The remaining sales are desktop computers, so we can calculate the number of desktop computers as:
Number of desktop computers = Total computers - Number of laptops - Number of netbooks
Number of desktop computers = 72 - 36 - 24 = 12 desktop computers

Therefore, the number of desktop computers sold is 12
