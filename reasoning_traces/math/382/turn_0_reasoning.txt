Given information:
- It takes David 10 minutes to wash 4 windows.
- David's house has 64 windows.

To find the total time it will take David to wash all 64 windows, we need to find the rate at which David can wash the windows and then multiply it by the total number of windows.

Step 1: Find the rate at which David can wash the windows.
Rate = Number of windows / Time taken
Rate = 4 windows / 10 minutes
Rate = 0.4 windows per minute

Step 2: Find the total time it will take David to wash all 64 windows.
Total time = Total number of windows / Rate
Total time = 64 windows / 0.4 windows per minute
Total time = 160 minutes

Therefore, it will take David 160 minutes (or 2 hours and 40 minutes) to wash all 64 windows.
