Given information:
- There are 5 coaster vans used to transport students.
- Each van carries 28 students.
- 60 of the students are boys.

To find the number of girls, we need to:
1. Calculate the total number of students.
2. Subtract the number of boys from the total number of students.

Step 1: Calculate the total number of students.
Total number of students = Number of students per van × Number of vans
Total number of students = 28 × 5 = 140 students

Step 2: Subtract the number of boys from the total number of students.
Number of girls = Total number of students - Number of boys
Number of girls = 140 - 60 = 80 girls

Therefore, the number of girls on the field trip is 80.
